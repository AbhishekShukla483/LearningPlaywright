JavaScript Explained Simply

Quick Interview Preparation Guide

🚀 What is JavaScript?

JavaScript (JS) is a lightweight, interpreted programming language that makes websites interactive. It runs in the browser and can also run on servers (Node.js).
⬇
Think of it this way:
• HTML = Structure (skeleton)
• CSS = Style (appearance)
• JavaScript = Behavior (brain/actions)

⭐ Key Features (Interview Points)

Interpreted

No compilation needed. Code runs line by line in the browser.

Dynamic Typing

No need to declare variable types. let x = 5; then x = "hello";

Event-Driven

Responds to user actions like clicks, scrolls, and key presses.

First-Class Functions

Functions can be stored in variables, passed as arguments, and returned.

Prototype-Based

Objects inherit directly from other objects (not classes, though ES6 has class syntax).

Single-Threaded

Executes one task at a time but uses event loop for async operations.

📦 Data Types

Primitive (7 types):

let str = "Hello"; // String let num = 42; // Number let flag = true; // Boolean let nothing = null; // Null (intentional empty) let notDefined; // Undefined (not assigned) let sym = Symbol("id"); // Symbol (unique identifier) let big = 9007199254740991n; // BigInt (huge numbers)

Non-Primitive:

let obj = { name: "Alice", age: 25 }; // Object let arr = [1, 2, 3]; // Array (special object) function greet() {} // Function (callable object)
💡 Interview Tip: Primitive types are stored by value. Objects are stored by reference (in heap memory).

🔧 Variables: var, let, const

Keyword Can Reassign? Can Redeclare? Scope Hoisted?
var ✅ Yes ✅ Yes Function ✅ Yes (initialized undefined)
let ✅ Yes ❌ No Block ✅ Yes (not initialized)
const ❌ No ❌ No Block ✅ Yes (not initialized)
💡 Interview Tip: Always use const by default. Use let only when you need to reassign. Avoid var to prevent scope-related bugs.

⚙ Functions

Ways to create functions:

// 1. Function Declaration (hoisted) function add(a, b) { return a + b; } // 2. Function Expression (not hoisted) const multiply = function(a, b) { return a * b; }; // 3. Arrow Function (concise, no own 'this') const subtract = (a, b) => a - b;
💡 Interview Tip: Arrow functions don't have their own this, arguments, or super. They inherit this from the surrounding scope.

🔭 Scope & Hoisting

Global Scope

Variables declared outside any function. Accessible everywhere.

Function Scope

Variables declared inside a function. Only accessible inside that function.

Block Scope

Variables declared inside {} (if, for, etc.). Only let and const respect this.

Hoisting: JavaScript moves declarations to the top of their scope during compilation.
• var declarations are hoisted and initialized as undefined
• let and const are hoisted but NOT initialized (Temporal Dead Zone)
• Function declarations are fully hoisted

🔒 Closure (Important Interview Topic)

A closure is a function that remembers and accesses variables from its outer scope, even after the outer function has finished executing.
function counter() { let count = 0; return function() { count++; return count; }; } const myCounter = counter(); console.log(myCounter()); // 1 console.log(myCounter()); // 2
💡 Interview Tip: Closures enable data privacy (private variables) and are used in callbacks, event handlers, and functional programming patterns.

⏱ Asynchronous JavaScript

JavaScript handles async operations using:

// 1. Callbacks (older way) setTimeout(() => { console.log("Done!"); }, 1000); // 2. Promises fetch("https://api.example.com/data") .then(response => response.json()) .then(data => console.log(data)) .catch(error => console.error(error)); // 3. Async/Await (modern, cleaner) async function getData() { try { const response = await fetch("https://api.example.com/data"); const data = await response.json(); console.log(data); } catch (error) { console.error(error); } }
💡 Interview Tip: JavaScript is single-threaded. The Event Loop handles async callbacks by moving them from the callback queue to the call stack when it's empty.

✨ ES6+ Features to Mention

  • let / const — block-scoped variables
  • Arrow functions — concise syntax, lexical this
  • Template literals — `Hello ${name}`
  • Destructuring — const {name, age} = person;
  • Spread/Rest — ... operator
  • Promises & Async/Await — cleaner async code
  • Modules — import / export
  • Classes — syntactic sugar over prototypes
  • Map & Set — new data structures
  • Default parameters — function greet(name = "Guest")
