# VS Code: Default Keyboard Shortcuts (Windows)

> Essential shortcuts to boost your productivity in Visual Studio Code:.

---

## File Operations

| Action | Shortcut | Description |
|:---|:---|:---|
| Open File | `Ctrl + O` | Open a file from your computer |
| Save File | `Ctrl + S` | Save the current file |
| Save All | `Ctrl + K` `Ctrl + S` | Save all open files |
| New File | `Ctrl + N` | Create a new untitled file |
| Close File | `Ctrl + W` | Close the current editor tab |
| Close All | `Ctrl + K` `Ctrl + W` | Close all editor tabs |
| Reopen Closed Tab | `Ctrl + Shift + T` | Reopen the last closed editor tab |

---

## Basic Editing

| Action | Shortcut | Description |
|:---|:---|:---|
| Undo | `Ctrl + Z` | Undo last action |
| Redo | `Ctrl + Y` | Redo last undone action |
| Cut | `Ctrl + X` | Cut selected text |
| Copy | `Ctrl + C` | Copy selected text |
| Paste | `Ctrl + V` | Paste from clipboard |
| Select All | `Ctrl + A` | Select all text in file |

---

## Find and Replace

| Action | Shortcut | Description |
|:---|:---|:---|
| Find | `Ctrl + F` | Find text in current file |
| Replace | `Ctrl + H` | Find and replace in current file |
| Find in Files | `Ctrl + Shift + F` | Search across all project files |
| Replace in Files | `Ctrl + Shift + H` | Replace across all project files |

---

## Navigation

| Action | Shortcut | Description |
|:---|:---|:---|
| Go to Line | `Ctrl + G` | Jump to a specific line number |
| Go to File | `Ctrl + P` | Quick open any file by name |
| Go to Symbol | `Ctrl + Shift + O` | Jump to functions/variables in file |
| Go to Definition | `F12` | Jump to where symbol is defined |
| Peek Definition | `Alt + F12` | Show definition inline without leaving file |
| Go Back | `Alt + Left` | Go back to previous cursor location |
| Go Forward | `Alt + Right` | Go forward to next cursor location |
| Command Palette | `Ctrl + Shift + P` | Access all VS Code: commands |

## Code Editing

| Action | Shortcut | Description |
|:---|:---|:---|
